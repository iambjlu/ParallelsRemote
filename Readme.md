# Parallels Remote

在手機(或任何瀏覽器)上遠端控制 Mac 上的 Parallels Desktop 虛擬機。

Mac 端是一個常駐選單列的 SwiftUI App,內建網頁伺服器;手機用瀏覽器開啟網址就能操作,不需要安裝任何東西。

## 功能

- **電源**:開機、正常關機、休眠(suspend)、暫停(pause)、恢復、強制關機
- **快照**:建立(預設名稱為目前時間)、還原、刪除,以及一鍵「回復到最後一個快照」
- **複製機器**:用 APFS clone 瞬間複製,可自訂名稱;執行中的機器會先休眠、複製完自動恢復
- **刪除機器**:按鈕確認後連同檔案永久刪除
- **網卡**:顯示每張網卡的類型(Shared / Bridged / Host-Only)與 MAC,可拔掉 / 連回(僅限執行中的機器)
- **IP**:每個 IP 一行並標示網卡類型,點一下即可拷貝
- **端口轉發**:依機器分組顯示,可新增 / 刪除,並可拷貝「目前連線位址:Mac 埠」
- **登入密碼**:在 Mac 的設定視窗設定,網頁端要輸入密碼才能控制
- **HTTPS(自簽憑證)**:可選;同一個埠收到明文 HTTP 會自動轉址到 `https://`
- **網卡名稱**:選單列與設定視窗顯示系統上的網卡名稱(例如 Wi-Fi、Ethernet、Tailscale),不是 `en0` 這類代號
- **選單列常駐**:啟動時只在選單列;開啟主視窗期間 Dock 才有圖示,關掉後回到只有選單列

## 需求

- macOS 15 或更新
- 已安裝 Parallels Desktop(使用 `prlctl`、`prlsrvctl`,預設路徑 `/usr/local/bin`)
- Swift 6 工具鏈(Xcode)

## 執行

```bash
swift run                 # 開發用:直接執行
scripts/make_app.sh       # 打包成 build/ParallelsRemote.app(ad-hoc 簽章)
```

啟動後選單列會出現伺服器圖示。點圖示 →「開啟主視窗…」可以看到連線網址、設定密碼與 HTTPS。
手機瀏覽器開啟選單列顯示的網址(例如 `http://192.168.31.90:8888/`)即可。

> **開機自動啟動**需要使用打包後的 `.app`(`SMAppService` 的限制);用 `swift run` 執行時,設定視窗會提示這一點。

## 設定

設定視窗(選單列 →「開啟主視窗…」):

| 項目 | 說明 |
|---|---|
| 連線 | 服務狀態、連接埠(預設 8888,可修改,套用後會重啟服務)與各網卡的連線網址,可一鍵拷貝 |
| 登入密碼 | 設定 / 更換 / 清除。設定後網頁需要輸入密碼;更換密碼會登出所有裝置 |
| HTTPS | 開啟後以自簽憑證提供服務,瀏覽器會警告,選擇繼續前往即可 |
| 登入時自動啟動 | 需要 `.app` |
| SSH 轉發起始埠 | 複製機器時自動建立的 SSH 轉發從這個埠往上分配 |

資料存放在 `~/Library/Application Support/ParallelsRemote/`(`config.json`、`auth.json`、`tls/`)。

## 使用上的注意事項

- **只接受內網來源**:區網(`10/8`、`172.16/12`、`192.168/16`)、Tailscale(`100.64/10`)與本機。沒設密碼時,這些網路內的人都能控制虛擬機,建議設定密碼。
- **回復快照會丟棄變更**:機器會回到最後一個快照的狀態,之後做的修改全部遺失,無法復原。
- **複製出來的機器是「冷開機」**:執行中複製時,副本的記憶體狀態會被移除(才能重設 MAC),等同斷電後開機。
- **Linux 副本的 IP 可能與原機相同**:複製後兩台的 `machine-id` 相同,DHCP 會發同一個 IP,兩台同時開機會互搶。
- **網卡拔掉 / 連回只能對執行中的機器操作**,這是 Parallels 的限制。
- **不支援 Passkeys**:WebAuthn 需要網域名稱,不能用 IP 位址連線。
